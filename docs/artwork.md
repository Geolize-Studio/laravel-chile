# Header artwork

The README header is an AI-generated engraving-style illustration grounded in a real photograph of the snow-covered central Chilean Andes. It is an original software-package design, not an official postage stamp.

## Final copy

- Title: **LARAVEL CHILE**
- Subtitle: **Thoughtful tools for Chilean applications.**

The artwork intentionally has no vendor name, module list, version, denomination, postal authority, or official emblem. Its broad description remains useful as the package evolves.

## References

1. **Landscape:** Sebastián Silva Solar's photograph of the snowy Andes near Santiago, [Unsplash photo x71MHPaMCv8](https://unsplash.com/pt-br/fotografias/montanha-coberta-de-neve-sob-o-ceu-azul-durante-o-dia-x71MHPaMCv8). The photo informed the broad ridgeline, gullies, snow distribution, and low cloud layer. [Unsplash license](https://unsplash.com/license).
2. **Print and material:** the historical landscape issue documented by the [Sociedad Filatélica de Chile, Vistas y Paisajes 1938–1956](https://www.sociedadfilatelica.cl/SOFICH_HTML/webemisiones_1900_1949/emision1938_56.html), specifically the blue engraved issue numbered 261. This was a reference for fine ink linework, perforations, and paper texture. Its landscape, denomination, postal branding, and original composition were not reproduced in the final design.

Reference downloads are local working materials under ignored `.omx/references/`; they are not part of the public package. Do not apply the package's code license to third-party source imagery.

## Art direction

A wide, flat, panoramic stamp with restrained navy ink on warm ivory paper. The landscape retains the mass and structure of the photographic reference instead of inventing a generic dramatic peak. Snow is negative space; shadows use fine engraved linework. The design uses centered serif typography and small red accents, with no tourism collage or software icons.

## Generation record

Generated with Codex's built-in image generation tool. The first pass used the photograph as the terrain reference and the historical stamp as the printing reference. A second pass preserved the landscape and changed the text to match the final brief. The exact final editing prompt is in [artwork-prompt.txt](artwork-prompt.txt).

Final asset: [assets/readme-header.png](assets/readme-header.png), 2172 × 724 pixels. The generated output was copied unchanged into the repository; no programmatic image retouching was applied.

Visual inspection confirmed the snowy mountain composition, perforated border, exact final title/subtitle, and removal of vendor and module-list text. The README includes equivalent English alt text and text outside the image for accessibility and indexing.
