# Security

This package is unreleased. A published support window will accompany the first stable release.

Report vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/Geolize-Studio/laravel-chile/security/advisories/new). Reporting is enabled for this repository. Do not post an exploit, credentials, personal identifiers, or customer data in a public issue. Include a minimal reproduction, affected version, expected behavior, and security impact.

Security-sensitive boundaries include strict input parsing, checked integer arithmetic, territorial dataset validation, and source-maintenance workflows. Source documents must never execute code. Observing a remote change does not authorize replacing runtime data or publishing a release.

After the first stable release, fixes will follow semantic versioning. A data change that affects lookup or resolution must be documented even when the PHP API remains unchanged.
