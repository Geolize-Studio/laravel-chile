# Security

This package is unreleased. It has no published support window or private vulnerability-reporting channel yet.

Before publication, maintainers must enable GitHub private vulnerability reporting and replace this paragraph with the verified repository reporting link. Do not post an exploit, credentials, personal identifiers, or customer data in a public issue. Consumers of local development copies should contact the maintainer through their existing private project channel.

Security-sensitive boundaries include strict input parsing, checked integer arithmetic, territorial dataset validation, and source-maintenance workflows. Source documents must never execute code. Observing a remote change does not authorize replacing runtime data or publishing a release.

After the first stable release, fixes will follow semantic versioning. A data change that affects lookup or resolution must be documented even when the PHP API remains unchanged.
